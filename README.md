# Production Planning Optimisation using Pyomo, Pandas & GLPK

## Overview

This project develops a Mixed-Integer Linear Programming (MILP) model for production planning using Python, Pandas, Pyomo and GLPK.

The model determines an optimal production plan for multiple products while considering limited machine capacity, labour availability, raw-material availability and maximum market demand.

The objective is to maximise total production profit while satisfying the available operational resources and product demand constraints.
